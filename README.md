# 🌤️ Weather App

An elegant, responsive web-based weather application that provides real-time weather information for cities around the globe using the OpenWeatherMap API.

---

## 📌 Project Overview
The *Weather App* is a fast and responsive web application built with HTML, CSS, and JavaScript. Users can search for any city to instantly retrieve accurate weather details, including temperature, humidity level, and wind speed. The interface dynamically updates icons based on current weather conditions and offers an optimized mobile view.

---

## ✨ Features
- 🔍 *Real-time Search:* Search for any city worldwide to get live weather data.
- 🌡️ *Dynamic Temperature Display:* Displays temperature rounded off in Celsius.
- 💧 *Detailed Weather Metrics:* Shows humidity levels (%) and wind speed (km/h).
- 🖼️ *Dynamic Icons:* Changes weather icons dynamically (Clouds, Clear, Rain, Drizzle, Mist).
- 📱 *Mobile First & Responsive Design:* Fully responsive layout tailored for both desktop and mobile screens.
- ⚠️ *Error Handling:* Prompts alert messages for invalid city names.

---

## 🛠️ Tech Stack
- *Frontend:* HTML5, CSS3, JavaScript (ES6+)
- *API:* [OpenWeatherMap API](https://openweathermap.org/api)
- *Typography:* Google Fonts (Poppins)
